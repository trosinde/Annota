# ADR 0003: MSRV 1.91

Status: accepted by the maintainer 2026-11-22

## Context

CLAUDE.md §2 fixed the MSRV at Rust 1.85, the `rustc-1.85` package of Ubuntu 24.04 and the
default toolchain of Debian 13.

On 2026-11-22 Dependabot reported four advisories against the `zip` crate, which reads and
writes the `.annota` document format and the clipboard payload:

| Alert | Advisory | Severity | Fixed in |
|---|---|---|---|
| #1 | GHSA-m665-v7pm-7grj: parser differential via dual headers ("zip cloaking") | critical | 9.0.5 |
| #2 | GHSA-q7v9-x93c-xqv3: unbounded symlink-target allocation in `extract()` | high | 9.0.0 |
| #3 | GHSA-8hxf-qr8p-62x4: AES entry HMAC bypass on premature EOF | medium | 9.0.0 |
| #4 | GHSA-9hj8-73fh-9963: legacy Shrink/Reduce/Implode decoder DoS | high | 9.0.0 |

Every fixed release declares `rust-version` 1.88 (9.0.x to 9.7.x) or 1.89 (9.8.x). The last
release for Rust 1.85 (7.3.0) is inside all four vulnerable ranges. Annota does not reach any of
the four code paths: it reads only through `ZipArchive::by_name` into memory with fixed entry
names and size limits, never calls `extract()` or `ZipStreamReader`, and enables neither AES nor
the legacy decoders. The maintainer nevertheless chose to move to a fixed release rather than
dismiss the alerts, so that later `zip` fixes stay one `cargo update` away.

Ubuntu 24.04 ships `rustc-1.91`, `cargo-1.91`, `rustfmt-1.91` and `rust-1.91-clippy`
(1.91.1) in noble-updates and noble-security, installed under `/usr/lib/rust-1.91/bin`
(checked 2026-11-22 in an `ubuntu:24.04` container). It has no `rustc-1.88`.

## Decision

The MSRV is Rust 1.91. Ubuntu 24.04 builds with `cargo-1.91`/`rustc-1.91`; `debian/control`,
`debian/rules`, `build-aux/vendor.sh` and CI use that toolchain. `zip` moves from 6.0.0 to 9.8.x
with `default-features = false` and only `deflate-flate2`.

The §2 row becomes: "Rust, edition 2021, MSRV 1.91 (Ubuntu 24.04 package `rustc-1.91` from
noble-updates). Keep `Cargo.lock` compatible with 1.91. Debian 13 (Rust 1.85) is no longer a
build platform."

## Consequences

- Debian 13 can no longer build Annota with its own toolchain. The maintainer accepted this.
- Ubuntu 24.04 builds need the noble-updates (or noble-security) pocket enabled, as on every
  default installation and on the GitHub runners.
- Crates whose versions were held back for 1.85 (for example `jpeg-encoder` 0.6, see
  `Cargo.toml`) may now move forward. That is not part of this decision.
- Open pull requests built against the 1.85 toolchain need a rebase or a fresh CI run.
