Capture it. Mark it up. Make it obvious.

Annota is a native screenshot, annotation and screen-recording app for GNOME. Arrows, callouts, numbered steps and redaction stay editable until you export. Built in Rust with GTK 4 and libadwaita, shipped as a Debian package. Everything stays on your machine: no account, no cloud, no telemetry.

Architecture

One renderer for canvas and export.

Screen access goes only through xdg-desktop-portal, so Annota behaves the same on Wayland and X11 without special privileges. Canvas and exporter share one Cairo renderer: what you see is pixel for pixel what you get.

Get started

Open the repo in Claude Code and run the design gate.

AGENTS.md defines the stack, the bootstrap steps and the workflow. The first build step is the design kit, then the app shell.

$ cd Annota && claude
