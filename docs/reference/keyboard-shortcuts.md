# Keyboard shortcuts reference

The same list is in the app under **Ctrl+?**. Source: `data/ui/help-overlay.blp` and
`src/ui/editor/mod.rs`.

## Capture

| Action | Shortcut |
|---|---|
| Capture region | Print |
| Capture window | Alt+Print |
| Capture screen | Shift+Print |
| New capture (from the editor) | Ctrl+N |

## General

| Action | Shortcut |
|---|---|
| Open file | Ctrl+O |
| Paste image from clipboard | Shift+Ctrl+V |
| Preferences | Ctrl+, |
| Keyboard shortcuts | Ctrl+? |
| Close window | Ctrl+W |
| Quit | Ctrl+Q |

## Document

| Action | Shortcut |
|---|---|
| Save | Ctrl+S |
| Save as | Ctrl+Shift+S |
| Export | Ctrl+E |
| Copy image | Ctrl+C |
| Paste | Ctrl+V |
| Undo / Redo | Ctrl+Z / Ctrl+Shift+Z |
| Zoom in / out | Ctrl++ / Ctrl+- |
| Best fit / 100 % | Ctrl+0 / Ctrl+1 |
| Show properties | F9 |
| Rotate right / left | Ctrl+R / Ctrl+Shift+R |
| Flatten selection / all | Ctrl+T / Ctrl+Shift+T |
