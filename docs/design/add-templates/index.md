# add-templates — mockups

Templates are `.annota` documents with **slot objects** and theme tokens. They open in the normal editor
(shell = `kit/template.html`). All five built-in layouts are original Annota designs: a coral rule under the title,
round number badges, and plain neutral slot wells.

Sources: `src/*.html`, generated by `../add-capture-library/tools/build_tpl.py` (shared helpers in `mock.py`).
Renders: `png/<name>-{light,dark}@{1,2}x.png`. The document page stays white in dark style, as a canvas image does.

## Redlines

**Template page** (document content, rendered by the cairo renderer; drawn here at 60 %):
- Page width 1240 px at 100 %. Padding 48 px (24 at the 50 % drawing scale). Title 48 px/800, subtitle 26 px #6b6b73,
  theme rule 6 px high under the title, radius 3.
- Step guide: number badge 60 px circle in the theme colour with white 800 numerals, 28 px gap to the content; caption 28 px/700,
  detail 24 px #6b6b73; slot full width, height 340 px by default (fit), radius 12, well colour #f3f3f5.
- Empty slot: diagonal hatch (#f6f6f8 / #efeff2, 20 px), 3 px inset #c8c8d0, `image` icon 64 px + "Drop a capture" (bold) + "or click to choose from the library".
  Drag-over: wash `rgb(53 132 228 / 12%)`, 4 px accent outline, text "Release to place · fitted".
- Theme colours: the 8 Annota ink colours. Default Coral; Timeline default Teal.
- Before/After: "BEFORE" (#6b6b73) and "AFTER" (theme colour) labels at 24 px/800 with letter spacing .06em. The After slot gets a 4 px theme-colour ring; 56 px arrow badge between the slots.
- Timeline: 4 px line at 45 % theme colour, 32 px nodes with a white 8 px ring, time 24 px/800 in the theme colour, caption 26 px.
- Grid 2 × 2 / 3 × 2 and Comparison (2–3 columns): equal columns with a 24 px gutter; the Comparison column label in the theme colour.

**Chooser dialog**: 1140 × 640 (`AdwDialog`), header Cancel / "New from Template" / Create (suggested). Sidebar 190 px: Built-in (`template`, count),
My Templates (`star`, count). Cards: 132 px thumbnail well (card style, radius 12); selected = 2 px accent ring; title 14/700; description 12 px .55.
Options pane 290 px: per-template options (Step guide: Steps spin 2–8, Numbering switch, Theme swatches small 24 px) + a page-size note.
`Enter` = Create; double-click on a card = Create.

**Combine dialog**: 1060 × 700. Left column 420 px: Title/Subtitle entry rows; "Order and Captions" group with a + button (adds from the library);
rows: `drag-handle` (.5), number badge 22 px in Coral, thumbnail 64 × 44, caption entry, flat small `close`. Numbering switch, Theme swatches.
Right: `canvas-bg` preview, toggle group Step Guide / Comparison / Before / After / Grid / Timeline (choices that do not fit the count are disabled,
e.g. Before / After for 3 images). Keyboard reorder: `Alt+↑` / `Alt+↓` on a focused row.

**Tray selection**: selected tiles get a 2 px accent ring and a 20 px accent badge with the selection order (1, 2, 3).
OSD bar 18 px above the tray: "N selected" · Combine… (suggested, `template` icon) · Export… · close (clears the selection).

**Slot properties (sidebar)**: heading "Image Slot N" + subtitle (source name · size or "Empty"). Scale Fit/Fill toggle, Number, Caption entry row;
Replace… / Edit Image; Clear Slot (destructive text). A selected slot shows 4 handles + a "Fit"/"Fill" badge (accent pill, top-left).

**Save as Template dialog**: 500 px, Name entry row (focused), Slots list with checks (thumbnail 56 × 38, name, "Slot N · fit|fill"),
Keep Text as Sample switch. Stored in `~/.local/share/annota/templates/<name>.annota`.

**Shortcuts**: `Shift+Ctrl+N` new from template · in the tray `Ctrl+click` add to selection, `Ctrl+Shift+M` combine selection.
