# add-capture-library — mockups

The library is its **own window** (`AdwApplicationWindow` + `AdwNavigationSplitView`), opened with
`Ctrl+L` from any Annota window or from the app menu. MVP scope: All Captures, Recent and Trash only.
The Favourites, Collections, Tags and Folders sidebar sections and search come in
`add-library-organisation` and are **left out on purpose** here.

Sources: `src/*.html` (generated by `tools/build.py`, which uses the shared `tools/mock.py`;
the `add-library-organisation` and `add-templates` mockups use the same helpers). Renders:
`png/<name>-{light,dark}@{1,2}x.png`. To regenerate:
`cd docs/design/add-capture-library/tools && python3 build.py && cd ../../../.. && python3 tools/render-mockups.py docs/design/add-capture-library`.

## Redlines

**Window**
- Library window default 1280 × 800, minimum 360 × 480. Below 860 px the preview pane moves into a
  pushed `AdwNavigationPage`. Below 720 px the sidebar collapses (`AdwNavigationSplitView` collapsed / `AdwOverlaySplitView` overlay).
- Sidebar 280 px (`--sidebar-w`). Preview pane 320 px, `window-bg` with a 1 px start separator.
- Header bar 47 px (kit). Sidebar header: start = New Capture (`capture-region`), title "Annota", end = main menu (`open-menu`).
- Content header: start = view toggle (`grid-view` / `list-view`, `.toggle-group`, icon-only) + thumbnail slider
  (104 px, 3 marks, `zoom-out` glyph at .55 opacity); title = current source ("All Captures") + subtitle "N captures";
  end = sort button (flat, label + `pan-down`), preview toggle (`sidebar-show-right`, `.active` when open), close.
- The sidebar footer (separator above, 10/16 px padding) shows the folder icon, the library path in monospace 12 px, a status line at 12 px .75 and an 8 px dot (success = connected, warning = not reachable).

**Sidebar (MVP)**: All Captures (`library`, count), Recent (`timer`, last 50, no count), Trash (`trash`, count).
Nav rows 38 px, radius 6, gap 2.

**Grid**
- Content padding 0 18 px 18 px. Day heading: `.heading` 15/700 + caption "Weekday, D Month · N captures" at .55; 18 px above, 12 px below.
- Heading rules: Today, Yesterday, weekday name for the last 7 days (subtitle = date), "D Month YYYY" when older (subtitle = weekday).
- Tile widths per zoom step: small 120 × 90 frame, medium **150 × 112** (default), large 230 × 168. Gap 18 px vertical, 12 px horizontal.
- Frame: radius 9, `row-hover` fill, 1 px inset `separator`. Image fitted (contain) with 8 px inset and a 1 px `shade` outline.
- Name 13 px, single line, ellipsised. Meta 12 px .55: capture-type icon (12 px) + time.
  Type icons: region `capture-region`, window `capture-window`, screen `capture-screen`, clipboard `copy`, file `image`, video `record`.
- Video: duration pill bottom-right (OSD, 20 px high, `play` 12 px + m:ss). Plain image file: "PNG"/"JPG"/"WEBP" pill bottom-left.
- States: hover = `fill-flat-hover` frame + empty check circle (22 px) top-left; selected = `accent-a12` fill + 2 px inset `accent-bg`;
  focus = 2 px `accent-a50` outline, 2 px offset; selection mode = check circles on all tiles (accent filled + `check` when selected).

**List** (`GtkColumnView`): header 34 px, rows 44 px, thumbnail 44 × 32 (radius 4). Columns and widths:
Name 38 %, Captured 16 %, Application 16 %, Size 10 % (tabular), Type 12 %, Dimensions (rest). The sorted column header is in `accent` with `pan-down` (descending).

**Preview pane**: image well 196 px high, radius 12, `canvas-bg`. Title `title-4` at 17 px + flat small `pen` (rename).
Buttons: "Open in Editor" (suggested, grows), Show in Files (`folder`), Export (`export`). Header end: Copy (`copy`), more (`view-more`).
Property rows (`.row.property`, 7/12 px padding): Captured, Type, Application, Window title*, Source*, Dimensions ("W × H · scale N×"), File size ("… · .annota|PNG|MP4"), Location (monospace 12 px). Rows marked * appear only when known.

**Quick look**: overlay `rgb(0 0 6 / 93%)` with 6 px backdrop blur, over the whole window. Top bar: name (bold) +
"Today, 14:22 · App · W × H · i of N"; "Open in Editor" + close at the end (OSD buttons, white 14 % fill). Prev/next 42 px circular at the edges. The hint row at the bottom uses `kbd.key`.

**Action bar** (selection mode): `GtkActionBar`, `headerbar-bg`, separator on top. "N selected" bold, Select All (flat), spacer,
Open · Export… (`export`) · Copy to Folder… (`folder`) · Move to Trash (`trash`, destructive text colour).
The header in selection mode: start "Cancel", title "N Selected", subtitle "of 31 captures".

**Toasts**: "“<name>” moved to Trash" + Undo; NAS back: "Library server is back — N captures moved to <path>" + Show.

**Offline banner**: `.banner.warning`: "Library server not reachable — showing the last known captures, read-only. New captures are kept on this computer." + Retry.
While offline, rename/trash/drag-in are disabled (insensitive) for items on the share.

**Empty state**: `status-page` with `library` icon 128 px, title "No Captures Yet", description containing the hotkey as `kbd.key` pairs and the folder in monospace,
pill "Take Capture" (suggested), flat "Change Library Folder…".

**Shortcuts** (library window): `Ctrl+L` open/raise library · `Ctrl+F` search (from add-library-organisation) · `Enter` / double-click open ·
`Space` quick look · `F2` rename · `Ctrl+D` duplicate · `Ctrl+C` copy image · `Ctrl+E` export · `Del` move to trash · `Ctrl+A` select all ·
`Esc` leave selection mode · `Ctrl+scroll` / `Ctrl++` / `Ctrl+-` thumbnail size · `Ctrl+1` / `Ctrl+2` grid / list.

**Preferences › Library** (`AdwPreferencesDialog` page): Storage — "Keep Every Capture" (switch), "Library Folder" (`folder` prefix, path monospace, "Change…"),
"Contents" property row. "When the Library Folder Is Unavailable" — "Local Fallback Folder" (default `~/.local/share/annota/pending`),
"Move Pending Captures Automatically" (switch). Index — "Rebuild Library Index" + "Rebuild".

**Editor tray** (bottom of the editor, 104 px): group labels written vertically (13 px bold .55), items 112 × 80 (radius 8), current = 2 px accent inset,
an unsaved document has an 8 px accent dot, video items show the duration pill. The last tile is "Open Library · Ctrl+L". At most 50 recent items, scrolling horizontally.

## Open questions

1. Metadata scenario names the **Files** app; the kit has no Files-window sample, so the mockup uses Harbor Backup. The rows are the same.
2. Should **Recent** show a count? It is drawn without one (it is always the last 50).
3. Pending captures while offline: they are drawn as their own group above Today. Alternative: mix them into Today with a "pending" badge.
4. Videos in the spec are "media file + sidecar". Drawn as a tile with a duration pill; the duration is part of the index.
