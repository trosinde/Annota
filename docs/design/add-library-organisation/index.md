# add-library-organisation — mockups

Extends the library window from [add-capture-library](../add-capture-library/index.md). The sidebar gains
Favourites, then the **Collections**, **Tags** and **Folders** sections. Search lives in the content header (`Ctrl+F`).

Sources: `src/*.html`, generated by `../add-capture-library/tools/build_org.py` (shared helpers in `mock.py`).
Renders: `png/<name>-{light,dark}@{1,2}x.png`.

## Redlines

**Sidebar**: sections use `.section-title` (13 px bold .55, padding 12/10/6). Row height 38 px, gap 1 px.
- Favourites `star`, count. Collections: manual collection `folder`, smart collection `search`. Tags: 10 px colour dot
  (Annota palette, 1 px `borders` ring so ink/paper dots stay visible) + name + count. Folders: `folder` + folder display name + count.
- Drop target row: `accent-a25` fill + 2 px inset `accent-bg` outline. Context menus on collection/tag rows.

**Search header**: replaces the title. `.search-entry` max 440 px, centred; trailing match count (12 px .55) + clear icon.
The search toggle button (`search`) is `.active` while open. `Esc` clears, then closes. Results update while typing (debounce 80 ms).

**Match line under a tile**: source label on its own line (12 px .55: Name / Tag / Application / Window title / Website / Annotation / Screen text),
then the excerpt (12 px, max 1 line on tiles) with `<mark>`: `accent-a25` fill, 1 px `accent-a50` ring, radius 3.
Results keep the day grouping. Preview: the match region is drawn on the image as a translucent accent rectangle (`accent` 28 %, 1 px accent stroke).

**Filter bar**: 46 px row under the header, `view-bg`, separator below, padding 8/18. Chips 30 px pill: `accent-a12` fill, `accent` text,
key in regular weight, value bold, 22 px close target. "+ Filter" chip: outlined (`borders`), bold. End: "N of M" (12 px .55), flat small "Save as Smart Collection…", "Clear All".
Filter popover 300 px: category rows with icons — Date `timer`, Type `image`, Application `capture-window`, Website `share`, Tag `tag`, Collection `folder` — then a "Has Annotations" check.
Sub-pages have a back button, a search entry and check rows with counts.

**Tags in the preview**: "Tags" group label + boxed card holding chips (22 px pill, colour dot 8 px) and "+ Add Tag" (outlined chip). The tag popover is 320 px:
current tags as removable chips ("x of N" when the selection is mixed), entry with the `tag` icon, autocomplete rows 34 px (prefix bold), `Enter` key hint on the
highlighted row, last row "Create Tag “…”". `Ctrl+T` opens it.

**Action bar (organisation)**: Tag… (`tag`), Add to Collection… (`folder`), Favourite (`star`), Export… (`export`), Trash (icon only, destructive colour).

**Tile badges**: favourite = 24 px OSD circle top-right with an amber filled `star`. It is shown only in Favourites and on hover/selection in other views, to keep the grid calm.

**Dialogs**: Delete Collection = `.alert` (Cancel / Delete destructive). Rename Tag = `.alert` with entry. New Smart Collection = 480 px dialog
(Cancel / Save) with Name entry row, rules as neutral chips, match count. Duplicates = 640 px dialog; groups as boxed rows of 150 px cards; the kept card has a 2 px
`success-bg` ring and a "Keep" success badge; header subtitle "N groups · N extra copies · size".

**Preferences › Library additions**: Additional Folders (header + button) with removable rows (path monospace, image count or "indexing x of y" + spinner);
Housekeeping: Clean Up Old Captures (switch, off by default), After (spin, days, 1–365), Next clean-up (property), Find Duplicates (Find…);
Search: Search Screen Text (switch; subtitle names Tesseract and the languages, runs on this computer).

**Shortcuts**: `Ctrl+F` search · `Ctrl+B` toggle favourite · `Ctrl+T` edit tags · `Ctrl+Shift+N` new collection · `Del` on a tag/collection row = delete (with alert).

## Open questions

1. Retention counts and the scenario: the toast reports moved items and "Review" opens Trash. Should retention also ask once the first time it is switched on?
2. The favourite badge on tiles is shown only in Favourites and on hover/selection. Always showing it is an option if the maintainer prefers.
3. Tag colours: drawn as user-choosable from the 8 Annota ink colours ("Change Colour"). This is not in the spec; it could be dropped.
4. Smart-collection rules are edited through the same chips UI ("Edit Rules…" puts the filter bar into edit mode). There is no separate rules editor.
