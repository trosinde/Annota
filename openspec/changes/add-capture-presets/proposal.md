# Add capture presets and advanced capture modes

**Roadmap phase:** Phase 2 (milestone 0.2–0.4)

## Why
Power users repeat the same captures; presets with their own hotkeys save time.

## What Changes
- Capture presets (mode, delay, cursor, effects, output) with own hotkeys
- Multi-area capture
- Time-lapse (interval) capture
- Capture info metadata (app, window title, URL where available)

## Benchmark features covered
- Custom capture presets
- Custom keyboard shortcuts per preset
- Multiple areas
- Time-lapse capture

## Out of scope
- Webcam still capture

## Capabilities

### New Capabilities
- none

### Modified Capabilities
- `capture`

## Impact
- Depends on the MVP changes being archived first.
