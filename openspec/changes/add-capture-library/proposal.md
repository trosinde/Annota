# Add capture library

**Roadmap phase:** Phase 2 (milestone 0.2–0.4)

## Why
After weeks of use, users need to find old captures quickly.

## What Changes
- Library view of all captures with grid, search, tags, filters (date, application, type)
- Metadata stored per capture
- Configurable retention

## Benchmark features covered
- Library
- Search
- Filter and sort by date/app
- Tags

## Out of scope
- Cloud sync

## Capabilities

### New Capabilities
- `capture-library`

### Modified Capabilities
- none

## Impact
- Depends on the MVP changes being archived first.
