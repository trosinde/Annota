# Add templates and image combining

**Roadmap phase:** Phase 2 (milestone 0.2–0.4)

## Why
Step-by-step guides and comparisons need several captures on one page with consistent layout.

## What Changes
- Original Annota templates: step guide, side-by-side comparison, before/after, grid, timeline
- Combine selected captures into a template
- Placeholders, titles, captions, numbering, theme colours
- Save own layouts as templates

## Benchmark features covered
- Templates
- Combine images
- Numbered captions
- Custom templates

## Out of scope
- Premium template store
