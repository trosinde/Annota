# Add quick styles and themes

**Roadmap phase:** MVP (milestone 0.1)

## Why
Consistent annotations look professional. Users need one-click styles and a way to define a corporate theme that applies to all tools.

## What Changes
- Quick styles per tool (built-in + user-created) with favourites
- Themes: palette + fonts generating quick styles for all tools
- Theme import/export as `.annota-theme`

## Benchmark features covered
- Quick styles
- Favourites
- Themes (corporate design)
- Theme import/export and team sharing

## Out of scope
- Asset store / downloadable content

## Capabilities

### New Capabilities
- `style-system`

### Modified Capabilities
- none

## Impact
- New module `src/styles/`
