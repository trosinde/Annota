# Add text recognition (grab and edit text)

**Roadmap phase:** Phase 2 (milestone 0.2–0.4)

## Why
Users often need the text in a screenshot, or need to fix a typo in it without recapturing.

## What Changes
- Grab text from a whole capture or a selection to the clipboard
- Edit text in place: replace recognised text with matching font size and colour
- Text capture mode directly from the screen

## Benchmark features covered
- Grab Text
- Edit Text
- Text capture mode

## Out of scope
- Cloud OCR (never)

## Capabilities

### New Capabilities
- `text-recognition`

### Modified Capabilities
- none

## Impact
- Depends on the MVP changes being archived first.
