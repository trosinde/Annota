Notes:

- Every portal call after the first logged "host Registry not available (... Connection already
  associated with an application ID); the portal sees no app ID". That was a probe-tool bug: all
  `Portal` objects share one bus connection, the first Register (in `env`) succeeded and later ones
  are refused. The app ID was registered; the tool now registers once per process.
- After the cancelled Start, `Session.Close` failed with UnknownMethod: the portal had already
  removed the session. Annota must treat a cancelled Start as a closed session.
- P1: the monitor chooser appeared with a single monitor (the user had to choose and confirm).
- P4: one frame was saved to /tmp/annota-probe-cursor-hidden.png (cursor_mode hidden) for a visual
  check; not committed, result to be recorded by the maintainer.
- Interpretation for P2/P3 (to confirm against the design): stream `size` is logical
  (3072x1728), buffers are physical (3840x2160, factor = monitor scale 1.25); caps framerate is
  variable (0/1), about 30 buffers/s while the screen changed.
